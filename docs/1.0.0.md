**新版兽装穿戴设想讨论：**

直接可穿戴制作组件：头、爪子、脚爪、尾

不可穿戴直接制作组件：身体、腿

可穿戴二级合成组件：身体（含爪子）、腿（含尾）、伪全身体

身体（含爪子）：仅检测到其他均已穿戴时显示身体，其他时候仅显示爪子

腿（含尾）：仅检测到其他均已穿戴时显示腿，其他时候仅显示尾巴

伪全身体：仅检测到其他均已穿戴时显示身体，其他时候仅显示爪子

模型触发：检测到全部穿戴且身体为伪全身体时触发伪全模型，全部穿戴且身体为全装身体时触发全装模型，其余情况触发盔甲模型

模型需求：全装模型、伪全模型，单头模型，爪子模型，尾巴模型，脚爪模型，身体模型（仅作物品显示），腿模型（仅作物品显示），含爪身体模型（仅作物品显示），含尾腿模型（仅作物品显示），伪全身体模型（仅作物品显示）

**兽装品质评定：**

**成品兽装品质=(装师等级系数*兽装品质值)*（1+装师阶段加成）**

**装师等级系数=装师当前等级/装师满级等级*100％**

**兽装品质值**=材料品质参数*UI互动参数*部位品质固定值

部位品质固定值：头—175，身体—165，手爪—100，腿—165（曲+5），尾巴—95，脚—100

UI互动参数：玩家获得的所有UI互动分数/所有UI互动的总分数*100％

材料品质参数：（海绵头骨=*1，树脂头骨=*0.6，粘液球粘合=*1，树脂粘合=*0.5）总参数=1*上述乘积*填充混搭程度

填充混搭程度：1-（占比最大填充数/总填充数）*（使用填充种类数/2）

装师阶段加成：新手装师-2%，初级装师0%，熟练装师+2%，老手装师+4%，满级+8%

**品质分阶****比例****：（成品兽装品质/极限品质）*100%**

**D（0~1.25%），C（1.26~13.75%），B（13.76~26.25%），A（26.25~51.25%），S（51.26~95%），S+（95.01~99.99%），S++（≥100%）****部位合成时，合成品取前合成物品质分阶比例均值并重新评定品质（例：0%{D}爪+100%{S++}身=50%{A}身包含爪）**

品质加成：D（减益）；C~B（无）；A~S（少量增益）；S+~S++（较多增益）

**装师等级制度：**

阶段：新手装师（10lv）-初级装师（10lv）-熟练装师（20lv）-老手装师（40lv）

等级提升：1.做某个部位获得的经验=材料品质参数*UI互动参数***兽装固有品质值**

2.接委托获得的经验=接委托所需级数*部位品质固定值/100【20级以后才能接】

升到下一级的经验=100×(0.5×(当前等级+1))

- 均可：【潜能无限、结晶稳定】结晶

- 【负面消除】结晶的使用：一手拿结晶，一手拿需要消除负面特性的部位，shift+右键，即可按由上至下的顺序消除1负面特性，同时结晶消失（无负面特性不可使用）

- 特性的获得与继承：镶嵌未损坏的特性结晶或者进行制作时，兽装会获得不同特性，（除【潜能无限、瞬间失忆】结晶外，）相同种类结晶无法重复镶嵌；与制作获得的特性相同的特性结晶可镶嵌，并取等级更高的体现（不会覆盖而使制作特性消失，仅为不体现）；当组件合成时（如爪+身=身包含爪），后者继承前者的制作属性并保留前者的特性结晶拓展槽内结晶（若后者槽位不足则掉落）
