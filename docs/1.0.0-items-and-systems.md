## 三、核心机制

### 3.1 穿戴结构与模型触发

```
直接可穿戴制作组件：头、爪子、脚爪、尾
不可穿戴直接制作组件：身体、腿
可穿戴二级合成组件：身体（含爪子）、腿（含尾）、伪全身体
```

**模型触发规则**

| 条件 | 模型 |
|---|---|
| 全部穿戴 且 身体为**伪全身体** | 伪全模型 |
| 全部穿戴 且 身体为**全装身体** | 全装模型 |
| 其余情况 | 盔甲模型 |

**模型需求（11 个）**：全装模型、伪全模型、单头模型、爪子模型、尾巴模型、脚爪模型、身体模型、腿模型、含爪身体模型、含尾腿模型、伪全身体模型
（其中「身体模型 / 腿模型 / 含爪身体模型 / 含尾腿模型 / 伪全身体模型」**仅作物品显示**）

### 3.2 品质评定

```
成品兽装品质 = (装师等级系数 × 兽装品质值) × (1 + 装师阶段加成)

装师等级系数 = 装师当前等级 / 装师满级等级 × 100%
兽装品质值   = 材料品质参数 × UI互动参数 × 部位品质固定值
```

**部位品质固定值**

| 部位 | 固定值 |
|---|---|
| 头 | 175 |
| 身体 | 165 |
| 手爪 | 100 |
| 腿 | 165（曲腿 +5） |
| 尾巴 | 95 |
| 脚 | 100 |

**UI互动参数** = 玩家获得的所有 UI 互动分数 / 所有 UI 互动的总分数 × 100%

**材料品质参数**

```
总参数 = 1 × (海绵头骨 ×1 | 树脂头骨 ×0.6) × (粘液球粘合 ×1 | 树脂粘合 ×0.5) × 填充混搭程度

填充混搭程度 = 1 - (占比最大填充数 / 总填充数) × (使用填充种类数 / 2)
```

**装师阶段加成**：新手 −2% · 初级 0% · 熟练 +2% · 老手 +4% · 满级 +8%

**品质分阶比例** = 成品兽装品质 / 极限品质 × 100%

| 阶 | 比例区间 | 加成 |
|---|---|---|
| D | 0 ~ 1.25% | 减益 |
| C | 1.26 ~ 13.75% | 无 |
| B | 13.76 ~ 26.25% | 无 |
| A | 26.25 ~ 51.25% | 少量增益 |
| S | 51.26 ~ 95% | 少量增益 |
| S+ | 95.01 ~ 99.99% | 较多增益 |
| S++ | ≥ 100% | 较多增益 |

> ⚠️ 原文档 B 段上限与 A 段下限同为 26.25%，需确认边界归属。

**合成继承**：合成品取前合成物品质分阶比例**均值**并重新评定。
例：0%{D}爪 + 100%{S++}身 = 50%{A} 身包含爪

### 3.3 装师等级制度

**阶段**：新手装师(10lv) → 初级装师(10lv) → 熟练装师(20lv) → 老手装师(40lv)
（满级 = 80 级）

**经验获取**

```
1. 做某个部位：经验 = 材料品质参数 × UI互动参数 × 兽装固有品质值
2. 接委托：    经验 = 接委托所需级数 × 部位品质固定值 / 100     【20级以后才能接】
```

**升级需求**：`升到下一级的经验 = 100 × (0.5 × (当前等级 + 1))` = 50 × (当前等级 + 1)

### 3.4 制作步骤

**通用流程**

| # | 方块 | 配方 |
|---|---|---|
| 1 | 熔炉 | 树脂 → 定型树脂 |
| 2 | 工作站 | 树脂碎片 + 雕刻刀 → 雕刻树脂碎片（指甲/牙齿共用） |
| 3 | 毛布制作台 | 1皮革 + 2棉花/1羊毛 + 染料 → 毛布（**10% 产出，10/100**） |
| 4 | 树脂收集器 | 云杉树/橡树 + 树脂收集器 + 瓶子 → 一瓶树脂（有冷却，须在对应生物群系回复） |
| 5 | 工作台 | 一瓶树脂 → 树脂 + 玻璃瓶 |
| 6 | 树脂收集器 | 粘液球右键 → 冷却归零 |
| 7 | 工作台 | 皮革外套 + 8树脂 → 身体DTD（未定型） |
| 8 | 工作台 | 皮革护腿 + 8树脂 → 直腿DTD（未定型） |
| 9 | 穿戴 | 穿戴未定型DTD一段时间 → 定型DTD |

> 定型期间限制：**身体 DTD ban 左右手；腿 DTD ban 移动**
> 时间不足脱下 → 返还掉一定耐久的对应皮革装备 + 1~3 树脂

**各部位流程**

- **头**：海绵头骨 / 树脂头骨 / 骨头头骨（彩蛋）→ 兽装眼睛 → 舌头 → 兽装头（未剃毛）→ 用剪刀剃毛得兽装头
- **手爪**：兽爪版型 → 肉垫(手指) → 肉垫(手掌) → 兽爪 → 2兽爪 = 一对兽爪
- **尾**：尾巴版型 → 兽装尾
- **脚爪**：兽脚底（海绵4个 / 树脂1个）→ 兽脚 → 兽脚×2 = 一对兽脚
- **身体**：各色毛布 + 8棉花/4海绵/4羊毛 + 身体DTD + 针线盒
- **腿**：直腿DTD + 树脂5 = 曲腿DTD；直腿用 10棉花/5海绵/5羊毛，曲腿用 16棉花/8海绵/8羊毛

### 3.5 穿戴效果

> **潮湿度与脏污值若各部件不同，则穿上均摊**

#### 高温 / 中暑

```
温度 > 1.2 时：每 (1 + 潮湿度/100) 秒，有 (过热常数 × 所处温度)% 概率使「中暑」+1 级
```

| 项目 | 规则 |
|---|---|
| 耐久 | 每种特性结晶 **2048** 耐久 |

#### 冲突机制

- **冲突对**：迅捷 ↔ 突围；失败制作 ↔ 弹簧锁

### 3.10 接单、委托与交易

#### 接单

- **委托需求内容**：等级限制、设计图、需求制作部位、品质底线、预计报酬、时间限制
- **接取**：栏位放 1 张空白设计图纸 → 复制委托设计图 → 立即获得**预计报酬的 25%**
- **预计报酬**：随等级限制、设计图复杂度、品质底线、需求部位增加而增加；随时间限制减少而增加
- **接取上限**：`floor(当前等级 / 10)`
- **交付**：放对应设计图 + 符合要求的部位 → 获得剩余报酬 + 装师经验
  - 优质制作超过品质底线 → 额外打赏 `(实际品质比例 / 品质底线比例 × 预计报酬 × 0.5)`
  - 缺失物品或不符合需求 → 无法交付
- **放弃**：放对应设计图 + 预计报酬的 25%
  - 超时 = 自动放弃，栏目不消失，需偿还**预计报酬的 50%** 才消失
  - 全部还款前不可接取其他委托（**接取区封禁**）

#### 委托他人（玩家间）

- 合成：设计图纸 + 空白设计图纸 + 纸 = 委托单（不消耗原设计图纸）
- 流程：右键委托单 → 选需求 → 放预计报酬 → 选目标玩家 → 消耗
- 目标玩家手册刷新**高亮 + 异色**的玩家委托
- 失败：接取超时 / 正常放弃时，预计报酬返还委托方；制作超时放弃多惩罚的 25% 不返还
